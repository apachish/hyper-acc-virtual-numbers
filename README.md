# Hyper ACC Virtual Numbers Plugin

پلاگین مدیریت شماره‌های مجازی برای وب‌سایت Hyper ACC با اتصال به وب‌سرویس VirtuNum.

## ویژگی‌ها

### سمت کاربری (Frontend)
- نمایش لیست سرویس‌های موجود با طراحی مدرن و ریسپانسیو
- نمایش کشورهای هر سرویس با قابلیت خرید
- صفحه‌بندی سرویس‌ها
- جستجو و فیلتر
- اتصال به کیف پول TeraWallet برای پرداخت

### سمت مدیریت (Admin)
- مدیریت درخواست‌های خرید
- تغییر وضعیت درخواست‌ها
- تنظیمات نرخ دلار و حاشیه سود
- مدیریت کش و تنظیمات API

## نصب و راه‌اندازی

1. فایل‌های پلاگین را در پوشه `wp-content/plugins/hyper-acc-virtual-numbers` کپی کنید
2. پلاگین را از پنل مدیریت وردپرس فعال کنید
3. تنظیمات API را در بخش "شماره‌های مجازی" > "تنظیمات" وارد کنید

## تنظیمات

### تنظیمات API
- **کلید API**: کلید دسترسی به وب‌سرویس VirtuNum
- **آدرس API**: آدرس پایه وب‌سرویس
- **مدت کش**: مدت زمان ذخیره‌سازی اطلاعات در کش (ثانیه)

### تنظیمات مالی
- **نرخ دلار**: نرخ تبدیل دلار به تومان
- **حاشیه سود**: درصد سود اضافه شده به قیمت پایه

## استفاده

### شورت‌کدها

#### نمایش سرویس‌ها
```
[havn_services]
```

#### نمایش خریدهای کاربر
```
[havn_user_purchases]
```

### ساختار API

#### دریافت سرویس‌ها
```php
$api = new HAVN_API();
$services = $api->get_services();
```

#### دریافت کشورهای یک سرویس
```php
$countries = $api->get_service_countries($service_id);
```

#### خرید شماره
```php
$result = $api->purchase_number($service_id, $country_code, $user_id);
```

## دیتابیس

پلاگین جداول زیر را ایجاد می‌کند:

### `wp_havn_purchases`
- `id`: شناسه یکتا
- `user_id`: شناسه کاربر
- `service_id`: شناسه سرویس
- `country_code`: کد کشور
- `price`: قیمت
- `status`: وضعیت
- `api_response`: پاسخ API
- `created_at`: تاریخ ایجاد
- `updated_at`: تاریخ بروزرسانی

### `wp_havn_services`
-  اطلاعات سرویس خرید شده

### `wp_havn_countries`
-  اطلاعات کشور خرید شده

## اتصال به TeraWallet

پلاگین به صورت خودکار با کیف پول TeraWallet متصل می‌شود:

- بررسی موجودی کاربر
- کسر مبلغ از کیف پول
- ثبت تراکنش

## تست

برای تست پلاگین:

1. پلاگین را فعال کنید
2. صفحه "شماره‌های مجازی" را باز کنید
3. روی دکمه "دریافت" یک سرویس کلیک کنید
4. کشورهای آن سرویس را مشاهده کنید
5. روی دکمه "خرید" کلیک کنید

## پشتیبانی

برای پشتیبانی و گزارش مشکلات، لطفاً با تیم Hyper ACC تماس بگیرید.
